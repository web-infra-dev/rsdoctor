# autoOpenBrowser

- **Type:** `boolean`
- **Optional:** `true`
- **Default:** `true`

Set to `false` to prevent Rsdoctor from opening the report in a browser after compilation. Report generation and the report server are unaffected. To close the report server after analysis, use [`disableClientServer`](./disableClientServer.mdx).
