# disableClientServer

- **Type:** `boolean`
- **Optional:** `true`
- **Default:** `false`

:::tip
In CI environments, Rsdoctor automatically disables the report server when `process.env.CI` is non-empty.
:::

Disables the Rsdoctor report server when set to `true`. Report data is still generated, so you can save it or inspect it later without keeping a server running.
