# CI/CD tutorial

Brief mode generates a self-contained report that can be stored as a CI artifact or uploaded to a CDN.

## Enable brief mode

Configure [`output.mode: 'brief'`](/config/options/output#mode) and include HTML in [`output.options.type`](/config/options/output#options). After the build, Rsdoctor writes `[outputDir]/rsdoctor-report.html`, which can be opened directly in a browser.

- Brief reports omit code data to keep the standalone file manageable.
- Use `output.reportDir` to change the output directory.
- Use `output.options.htmlOptions.reportHtmlName` to change the filename.

```js title="rspack.config.mjs"
import { RsdoctorRspackPlugin } from '@rsdoctor/core';

export default {
  plugins: [
    process.env.RSDOCTOR &&
      new RsdoctorRspackPlugin({
        output: {
          mode: 'brief',
          options: {
            type: ['html'],
          },
        },
      }),
  ].filter(Boolean),
};
```
