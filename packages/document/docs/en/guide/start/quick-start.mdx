# Quick start

This guide explains how to add Rsdoctor to your project.

## Requirements

- Node.js `^20.19.0 || >=22.12.0`
- Rspack 2.0 or later. Rsdoctor 2.0 does not support Rspack 1.x.

For framework integrations, check the Rspack version used by the framework. Installing a separate Rspack 2 dependency does not upgrade the framework’s bundler.
