# MCP server

Rsdoctor 2.x no longer includes `@rsdoctor/mcp-server`.

- Use [`@rsdoctor/agent-cli`](/guide/start/ai#agent-cli) for current AI-assisted build analysis workflows.
- See the [Rsdoctor 2.0 migration guide](/guide/migration/migration-v2#ai-workflow-migration) for migration steps.
- The previous MCP instructions are available in the [v1 documentation](https://v1.rsdoctor.rs/guide/usage/mcp).
