# 快速开始

本文档将介绍如何接入 Rsdoctor 能力。

## 环境要求

- Node.js 22.18 及以上版本
- Rspack 2.0 及以上版本。Rsdoctor 2.0 不再支持 Rspack 1.x。

## 第一步：安装依赖

import { PackageManagerTabs } from '@theme';

基于 Rspack 的项目（比如 Rsbuild 或 Rslib），安装以下依赖：
