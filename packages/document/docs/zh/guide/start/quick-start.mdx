# 快速开始

本文档将介绍如何接入 Rsdoctor 能力。

## 环境要求

- Node.js `^20.19.0 || >=22.12.0`
- Rspack 2.0 及以上版本。Rsdoctor 2.0 不再支持 Rspack 1.x。

使用框架集成时，请确认框架实际使用的 Rspack 版本。单独安装 Rspack 2 不会升级框架内部的构建工具。

## 第一步：安装依赖
