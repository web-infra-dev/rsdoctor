# MCP server

Rsdoctor 2.x 已不再包含 `@rsdoctor/mcp-server`。

- 当前 AI 构建分析流程请使用 [`@rsdoctor/agent-cli`](/guide/start/ai#agent-cli)。
- 迁移步骤请参阅 [Rsdoctor 2.0 迁移指南](/guide/migration/migration-v2#ai-工作流迁移)。
- 旧版 MCP 使用说明请参阅 [v1 文档](https://v1.rsdoctor.rs/zh/guide/usage/mcp)。
