# Plugin 分析

## 功能概览

在 **Compile Analysis** 下的 **Plugins Analysis** 页面，可以查看当前 Rspack 项目中 **Compiler Hooks** 和 **Compilation Hooks** 的调用数据：

<img
  src="https://assets.rspack.rs/others/assets/rsdoctor/plugins-analysis-overall.png"
  width={'600px'}
  style={{ margin: 'auto' }}
/>

:::tip
plugin 耗时中会计算 Rsdoctor 的内部插件耗时。
:::

## 名词释义

页面中数据统计表格内的字段含义如下：

| 名词                          | 描述说明                                                                               |
| ----------------------------- | -------------------------------------------------------------------------------------- |
| <b><i>Plugin Tap Name</i></b> | 代表 [.tap 调用时的 name 值](https://github.com/webpack/tapable#hookhookmap-interface) |
| <b><i>Hook</i></b>            | 代表 **hook 名称**                                                                     |
| <b><i>calls</i></b>           | 代表 **被调用的次数**                                                                  |
| <b><i>duration(total)</i></b> | 代表 **所有调用次数的时间总和**                                                        |
